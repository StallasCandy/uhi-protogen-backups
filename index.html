Personal backup utility

UHI Protogen Backups

A personal utility for saving selected UHI Protogen worker data to the operator's Google Drive account, so it can be recovered if the worker needs rebuilding.

How it works

The planned setup uses rclone to upload backup archives every seven days. Google account authorisation allows the utility to create and manage its backup files. This public website provides app information only.

Limited Google Drive access

The utility is configured to request the drive.file permission, for files created by or explicitly shared with the app. It does not request unrestricted access to every file in Google Drive.

For the operator's own use

This is not a public backup service. Backup archives and authentication credentials are not published on this website.

Read the privacy policy for details of access, storage, retention and deletion.
